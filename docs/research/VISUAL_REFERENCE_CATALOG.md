# Primeras conclusiones

## 1. No conviene una única plantilla

Las mejores series mantienen tipografía, firma, paleta o recursos gráficos, pero cambian la distribución de cada pieza.

## 2. El dato merece una familia propia

Las referencias B2B y de informes muestran que métricas, comparaciones y pequeños gráficos necesitan composiciones específicas. La familia `Data` debería pasar de ser solo una posibilidad a candidata formal del catálogo.

## 3. Screenshot y UI deben tratarse como contenido, no como fondo

Cuando la publicación pretende demostrar una aplicación, la pantalla debe conservar legibilidad y protagonismo. Debemos evitar mockups de dispositivos que reduzcan demasiado el área útil.

## 4. La identidad más útil es discreta

Los sistemas sostenibles no necesitan un logotipo enorme. Funcionan mejor mediante repetición de tipografía, microfirma, serie, paleta y reglas de composición.

## 5. El carrusel necesita narrativa, no solo páginas bonitas

Los casos más sólidos utilizan una progresión clara. Para Content Publisher el arquetipo debe definir también el papel narrativo de cada página.

## 6. Hay que evitar dos clichés

- “corporativo genérico”: degradados, tarjetas y formas sin relación con el contenido;
- “tech futurista genérico”: neón, robots y overlays usados solo para parecer tecnológico.

La identidad propia debe parecer profesional y contemporánea sin depender de esos recursos.
