# Plan de investigación visual

## Objetivo

Construir una biblioteca propia de arquetipos para LinkedIn a partir del estudio de referencias actuales, sin copiar layouts ni identidades de terceros.

## Qué buscamos

No buscamos “plantillas bonitas” de forma indiscriminada. Cada referencia debe aportar al menos una solución reutilizable en alguno de estos puntos:

- jerarquía tipográfica;
- composición de screenshots;
- uso de datos o métricas;
- explicación de arquitectura;
- secuencia narrativa de carruseles;
- anotaciones;
- before / after;
- portada;
- cierre;
- firma de autor;
- sistema de series;
- uso controlado del color;
- composición para lectura móvil.

## Método de análisis

Cada referencia se traducirá a patrones abstractos, no a copias.

Ejemplo:

> Referencia externa: portada con gran titular, bloque lateral de color y fotografía.

No se implementa como copia literal.

Se extrae:

> Patrón: `headline dominante + elemento visual secundario + firma estable`.

A partir de ese patrón se crea una composición nueva con proporciones, tipografía, geometría e identidad propias.

## Clasificación prevista

Cada patrón se etiquetará por:

- familia;
- objetivo narrativo;
- densidad;
- presencia de imagen;
- presencia de datos;
- número de páginas;
- tono visual;
- complejidad de implementación;
- idoneidad para móvil.

## Resultado esperado de la investigación

Antes de congelar el sistema visual se espera disponer de:

- 30–40 referencias estudiadas;
- catálogo de patrones extraídos;
- selección de 12 arquetipos candidatos para V1;
- tres direcciones distintas de identidad visual;
- pruebas con contenido real.

## Regla

Ninguna referencia externa se convierte directamente en plantilla de producto. Primero debe pasar por abstracción, rediseño y validación como arquetipo propio.
