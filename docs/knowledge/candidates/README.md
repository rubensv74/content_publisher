# Candidatos para la base de conocimiento

Esta carpeta recoge aprendizajes reutilizables generados durante Content Publisher que pueden tener valor fuera del proyecto.

## Qué debe entrar aquí

Ejemplos:

- patrones para sistemas de plantillas paramétricas;
- generación de imágenes desde componentes web;
- generación de PDF multipágina;
- integración desacoplada con APIs externas;
- modelado de flujos editoriales;
- estrategias de Design System para contenido generado;
- autenticación de aplicaciones personales;
- buenas prácticas de Next.js, React, TypeScript, Supabase o PostgreSQL descubiertas durante el desarrollo;
- errores relevantes y su diagnóstico cuando el aprendizaje sea generalizable.

## Qué no debe entrar aquí

- manuales de usuario específicos;
- descripción de una pantalla concreta;
- decisiones que solo tengan sentido dentro de Content Publisher;
- copias de documentación existente en otras carpetas.

## Formato recomendado

Cada nota candidata debería incluir:

1. problema o contexto general;
2. solución o patrón;
3. por qué funciona;
4. límites o riesgos;
5. ejemplo mínimo;
6. fuentes si aplica;
7. proyectos donde podría reutilizarse.

## Flujo posterior

Estas notas son candidatas, no la base de conocimiento definitiva. Más adelante podrán revisarse, depurarse y trasladarse al repositorio general de conocimiento evitando duplicados.
